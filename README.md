## Frontend Technology Stack

This project utilizes the following frontend technologies and tools:

### Core Framework and Build Tools
- **Vue 3**: Progressive JavaScript framework for building user interfaces with a component-based architecture.
- **Vite**: Fast build tool that provides a development server with hot module replacement and optimized production builds.
- **Vue Router**: Official router for Vue.js, enabling single-page application navigation.

### UI and Visualization Libraries
- **Element Plus**: Vue 3 component library based on Element UI, providing a set of high-quality UI components.
- **Mapbox GL JS**: Interactive maps library for web and mobile applications, used for map rendering and interactions.
- **AntV L7**: Geographic visualization engine for large-scale geospatial data, supporting 2D/3D maps and thematic layers.
- **AntV G2Plot**: Charting library for creating interactive and responsive data visualizations.
- **@opd/g2plot-vue**: Vue wrapper for AntV G2Plot, enabling chart components in Vue applications.

### Data and API Handling
- **Axios**: Promise-based HTTP client for making API requests to backend services.
- **Turf.js**: JavaScript library for spatial analysis, used for geographic calculations and operations.

### Development and Code Quality Tools
- **ESLint**: Static code analysis tool for identifying and fixing JavaScript/Vue code issues.
- **Prettier**: Code formatter that enforces consistent code style across the project.
- **Vite Plugin Vue DevTools**: Development tool for debugging Vue applications in the browser.

### Additional Libraries
- **Three.js** (inferred from model assets): 3D graphics library for rendering 3D models and scenes in the browser.
